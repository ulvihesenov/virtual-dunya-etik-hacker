## Haqqında

Bu layihə Azərbaycan dilində kibertəhlükəsizlik və etik hakerlik sahəsinə yeni başlayanlar üçün hazırlanmış maarifləndirici kitabdır.

Kitabın əsas məqsədi oxuculara rəqəmsal dünyanın iş prinsiplərini, informasiya təhlükəsizliyini və etik hakerliyin əsaslarını sadə və anlaşılan dildə təqdim etməkdir.

## About

This project is an educational book for beginners interested in cybersecurity and ethical hacking.

Its purpose is to introduce the fundamentals of the digital world, information security, and ethical hacking in an accessible way.
